The u8printf_s function composes a string via the format string and writes it, as utf-8, to the STDOUT file.

Parameters
[in]fmtformat-control string
[in]...optional arguments
Precondition
fmt shall not be a null pointer.
fmt shall not contain the conversion specifier n.
Returns
On success the total number of bytes written is returned.
On failure a negative number is returned.
Return values
-ESNULLPwhen fmt is NULL pointer
-EINVALwhen fmt contains n
-1on some other error. errno might be set then.
