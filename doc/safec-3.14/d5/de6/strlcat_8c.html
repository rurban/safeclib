EXPORT size_t strlcat ( char *restrict dest,
const char *restrict src,
size_t dsize )

strlcat appends the NUL-terminated string src to the end of the NUL-terminated string dest, but never writes more than dsize bytes in total (including the terminating NUL) and always NUL-terminates the result (unless dsize is 0 or dest is not already NUL-terminated within the first dsize bytes).

The caller must check whether truncation occurred by comparing the return value against dsize.

This is only compiled in when the platform libc does not already provide strlcat (see configure's HAVE_STRLCAT / cmake's HAVE_STRLCAT probe).

Returns
the total length of the string it tried to create, i.e. the initial length of dest plus the length of src. If the return value is >= dsize, the output was truncated.
