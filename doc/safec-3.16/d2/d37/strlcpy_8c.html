EXPORT size_t strlcpy ( char *restrict dest,
const char *restrict src,
size_t dsize )

strlcpy copies up to dsize - 1 characters from the NUL-terminated string src to dest, NUL-terminating the result (unless dsize is 0).

Unlike strncpy, it never writes more than dsize bytes in total and always NUL-terminates a non-zero sized buffer. The caller must check whether truncation occurred by comparing the return value against dsize.

This is only compiled in when the platform libc does not already provide strlcpy (see configure's HAVE_STRLCPY / cmake's HAVE_STRLCPY probe).
